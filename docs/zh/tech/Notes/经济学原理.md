# 第一章：经济学十大原理

**权衡取舍‌**：人们在做决策时必须放弃某些目标以实现另一目标。例如，时间分配上学习经济学可能减少娱乐时间，社会层面则涉及军事与民生（“大炮与黄油”选择）  
‌‌‌**机会成本‌**：机会成本是指为了得到某物所放弃的次优选择的价值。例如，大学生若选择学业可能放弃职业运动的收入（机会成本为数百万美元）。‌‌‌‌  
‌**理性人假设‌**：理性人通过比较边际收益与成本做决策。例如，多盛一勺饭的决策基于增量调整（边际量）。‌‌‌‌  
‌**激励反应‌**：政策或市场价格变化会通过影响成本收益改变行为。例如，燃油税激励转向电动车，而安全带法规可能间接导致事故增加。‌‌  
**‌贸易互利性‌**：国际贸易使双方都能以更低成本获得更多商品和服务，不存在“零和博弈”。‌‌‌‌  
‌**市场效率‌**：市场通过供求机制有效分配资源，减少浪费。计划经济国家转向市场证明其优越性。‌‌  
‌**政府干预的局限性‌**：政府有时能纠正市场失灵（如反垄断），但过度干预可能导致效率损失（如补 贴导致资源错配）。‌‌  
**‌生产决定生活水平‌**：国家或家庭的生活水平直接关联其生产能力。技术进步和专业化分工是经济增长的关键。‌‌  
**‌货币与通货膨胀‌**：货币供应过多会导致物价普遍上涨，侵蚀储蓄价值。‌‌  
**‌短期权衡**：政府在控制通胀与降低失业率之间面临选择，两者难以同时最优。‌‌  
# 价格弹性
弹性越大意味着需求量对价格越敏感。生活必需品弹性小，奢侈品弹性大。

# 比较优势
每个人生产具有比较优势的产品，然后进行交易，那么他们的情况都会变得更好。哪怕有个人什么事情都有绝对优势，也应该做最擅长的事情。

# 无谓损失
如果不由最低成本的卖者生产、不由最高评价的买者购买，则是无效率的，会造成无谓损失。  
自由市场生产使消费者和生产者剩余最大化的产量。

# 税收
税收负担由消费者和生产者共同负担。洗牌了供给和需求量，价格上涨导致一部分人不再购买，造成无谓损失。

# 进出口贸易
出口后国内价格上涨，消费者剩余下降；销量和价格增加，本土生产者剩余增加。  
进口后国内价格下降，消费者剩余增加；销量和价格下降，本土生产者剩余减少。  
关税使总福利减少，引起无谓损失（表面上是支付转移），和税的平方成正相关。
# 外部性
一个人的行为对旁观者福利的影响，不利的叫做负外部性，有利的叫做正外部性。

科斯定理：私人市场可以无成本地进行资源配置和协商，则总能解决外部性并有效配置。

现实生活中私人市场不那么有效的原因是沟通成本太高。

# 价格歧视
垄断厂商对相同商品或服务向不同消费者实施差异化定价的策略，旨在通过获取消费者剩余实现利润最大化。

**一级价格歧视（完全价格歧视）‌**  
特征：按消费者最高支付意愿逐一定价。   
实施难点：需精准掌握个体消费偏好。    
案例：高端定制服务（如珠宝定制）、艺术品拍卖。‌‌  

**‌二级价格歧视（数量定价）‌**
定价依据：消费数量阶梯定价。  
案例：水电燃气阶梯收费。‌‌批发市场量贩优惠。‌‌视频平台会员续费折扣。‌‌

**‌三级价格歧视（群体定价）‌。**
划分标准：地域、年龄、消费场景等。   
案例：旅游景区本地/外地游客票差。‌‌国际品牌区域定价策略（如星巴克中印价差）。‌‌电子产品首发高价与后期促销。‌‌

**纳什均衡（Nash Equilibrium）**  
定义：在非合作博弈中，如果每个玩家在知道其他玩家策略的情况下，都无法通过单方面改变自己的策略而获得更好的结果，那么这些策略的组合就构成了一个纳什均衡。

关键点：
每个玩家的策略是对其他玩家策略的最优反应。  
纳什均衡不一定是全局最优的结果，而是个体理性选择下的稳定状态。  
例子：在“囚徒困境”中，双方都选择“背叛”就是一个纳什均衡。

**囚徒困境（Prisoner's Dilemma）**
场景：两名罪犯被分开审讯，无法沟通。选择“合作”（不招供）或“背叛”（招供对方）。


对于囚徒困境的收益矩阵：

情况|对方合作|对方背叛
---|---|---
你合作| (-1, -1)| (-3, 0)
你背叛| (0, -3)	| (-2, -2)

检查纳什均衡：

如果对方选“合作”，你选“背叛”（0 > -1）。

如果对方选“背叛”，你选“背叛”（-2 > -3）。

因此，“背叛”是占优策略，均衡为（背叛，背叛）。

无论对方选择什么，“背叛”都是个人的最优策略。因此，（背叛，背叛）是纳什均衡，尽管这不是集体最优结果。
